# Руководство по внесению изменений (Contributing)

## Формат сообщений коммитов
Мы строго следуем спецификации Conventional Commits. Ваши сообщения коммитов должны начинаться с одного из префиксов:
- `feat:` — добавление нового функционала для пользователя (например: `feat: add division`)
- `fix:` — исправление багов и ошибок (например: `fix: resolve crash`)
- `ci:` — изменения в конфигурации авто-тестов и сборки
